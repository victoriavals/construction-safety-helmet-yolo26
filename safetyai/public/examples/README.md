# Foto contoh SafetyAI

Semua foto contoh menampilkan orang bersama helm, untuk mencoba alur deteksi pada situasi konstruksi. Contoh 1 dipertahankan. Contoh 2–4 menggantikan foto produk helm lama pada 16 November 2026.

Sumber: Roboflow, `naufalfirdaus/construction-safety-helmet-lnit7`, lisensi **CC BY 4.0** sesuai `dataset/README.dataset.txt` dan `dataset/data.yaml` pada export repository ini.

Dataset: https://universe.roboflow.com/naufalfirdaus/construction-safety-helmet-lnit7

| Aset website | Berkas sumber pada `dataset/test/images/` | Isi visual |
| --- | --- | --- |
| `workers-team-v2.jpg` | `ppe_0750_png_jpg.rf.o5WqydiG4VMBb4MP7Tg6.jpg` | Empat pekerja dengan helm dan rompi |
| `workers-helmet-use-v2.jpg` | `ppe_1070_png_jpg.rf.jEx3J3rWGoOnYZVJtmMI.jpg` | Tim dengan helm dipakai dan dibawa |
| `workers-inspection-v2.jpg` | `ppe_0716_png_jpg.rf.xwmIXlY6J8EKULwbi5bx.jpg` | Dua pekerja dengan helm meninjau rencana proyek |

Ketiga foto disalin byte-for-byte tanpa crop, perubahan warna, anotasi, atau pengubahan berkas dataset aslinya. Ukuran masing-masing 640 × 640 px. Nama URL baru memakai versi `v2` agar browser/CDN tidak menampilkan foto produk helm lama dari cache.

Deskripsi menjelaskan isi foto, bukan janji prediksi model. Hasil hanya tersedia setelah pengguna menjalankan analisis ke backend.
